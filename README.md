# 🎮 Gamer Suite & Fortnite Macro Tool

An all-in-one **AutoHotkey (AHK)** utility dashboard featuring Fortnite edit macros, an auto-clicker, macro recorder, crosshairs, system tools, and extra utilities.

---

## ⚡ Fortnite Macro Features

* **Single-Key Hold Edit (`F`):** Pressing `F` opens the edit mode and automatically holds select (`L`) for as long as you keep `F` held down. Releasing `F` closes/places the edit.
* **Spam Edit Macro (`I`):** Holding `I` rapidly loops the edit sequence (`F` $\rightarrow$ `G` $\rightarrow$ `L`) at top speed.
* **Master On/Off Toggle (`F8`):** Instantly switch the macros ON or OFF so you can type normally in chat or browser without interference.

---

## ⌨️ Quick Hotkey Reference

| Hotkey | Feature | Action |
| :--- | :--- | :--- |
| **`F` (Hold)** | Fortnite Macro | Single-button hold edit (`F` + hold `L`) |
| **`I` (Hold)** | Fortnite Macro | Rapid spam edit loop (`F` $\rightarrow$ `G` $\rightarrow$ `L`) |
| **`F8`** | Toggle | Enable / Disable Fortnite Macros |
| **`F6`** | Utility | Toggle Anti-AFK Routine |
| **`F9` / `F10`** | Recorder | Record / Replay Macro Sequence |
| **`Ctrl` + `Space`** | Windows | Pin active window on top |
| **`Ctrl` + `Shift` + `C`** | Overlay | Toggle custom center crosshair |
| **`Ctrl` + `Shift` + `V`** | Overlay | Cycle crosshair colors |

---

## 🚀 How to Run

1. Download and install [AutoHotkey v1.1+](https://www.autohotkey.com/).
2. Download or clone this repository.
3. Double-click the `.ahk` script file to launch the Gamer Suite.
4. Press **`F8`** in-game to enable your Fortnite macros!
